# PANG Zhouhao — Personal Homepage

Personal homepage built with plain HTML, CSS, and JavaScript (no frameworks, no build step, no external dependencies).

**Live site:** https://orange-suli.github.io

## Structure

```
index.html      — single-page site content
css/style.css   — styles (modern tech theme: dark hero + light body)
js/main.js      — mobile nav, scroll-reveal, active-section highlighting
favicon.svg     — site icon
```

## Development

Open `index.html` directly in a browser to preview.

## Deployment

Push to the `main` branch of this repository — GitHub Pages serves the site
automatically from the repo root.

```bash
git add .
git commit -m "Update homepage"
git push
```
